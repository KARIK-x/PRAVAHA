# PRAVAHA — Screenshot Gallery

Screenshots captured from the running PRAVAHA application (dev instance,
`http://127.0.0.1:10000`) on 2026-10-21. They use the application's real
stored NEPSE end-of-day market data (public market data, not personal
trading records). No portfolio, journal, or personal-account views are
included, to avoid exposing private information.

## Notes
- Data shown is stored end-of-day NEPSE data (public market data), not live.
- Personal portfolio, journal, and written-PDF views are intentionally excluded
